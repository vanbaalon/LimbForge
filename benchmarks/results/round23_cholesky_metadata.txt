Data: J (2n x n) QSC-like Jacobian columns as round 20 (column scale 2^[-60,60], entries within 2^-25..2^5 of it, 25% exact
zeros, a 2^-150 outlier in every 17th column). A = SYRK(J) (lower, one rounding per entry) with Marquardt damping
a_ii = RN(a_ii + 2^(e_ii - 10)). B: n x nrhs random, exponents in [-20, 20].

round23_cholesky.csv (FactorOptions defaults: block 32, host_macs 5e4, solve_host_macs 4e5):
  syrk_wall_ms: Linalg::syrk + damping (host). chol_*: Linalg::cholesky, median (and min) of 7 calls after one warm-up call;
  gpu = summed command buffers (updates), panel = host panel time, update = summed update wall time (overlaps the panel).
  gpu_updates / host_updates: trailing updates on the GPU / host. solve_*: Linalg::cholesky_solve with nrhs right-hand sides.
  e2e_wall_ms: SYRK + damping + Cholesky + solve in one sequence (median). host_only_chol_ms: the same factorization with
  every update on the host (gpu=false), once; gpu_equals_host = 1: bit-identical L (checked every row).
  mpfr_serial_chol_s: consumer-style right-looking MPFR Cholesky (mpfr_sqrt, mpfr_div, mpfr_mul + mpfr_sub per term) on one
  thread, measured at every n (serial_measured = 1). mpfr_parallel_chol_s: the same with the trailing update of each column
  split over 18 worker threads (division column also parallel). mpfr_serial_solve_s: MPFR forward/back substitution, serial,
  nrhs columns. speedup_vs_*: MPFR Cholesky time / LimbForge median Cholesky wall. e2e_mpfr_parallel_s: LimbForge SYRK +
  parallel MPFR Cholesky + serial MPFR solve (the consumer pipeline with only the SYRK replaced).
round23_cholesky_tuning.csv: block size x host_macs sweep (factorization wall/gpu/panel/update, solve wall, nrhs 4).
round23_cholesky_solve.csv: cholesky_solve with every update on the host, every update on the GPU (solve_host_macs 0) and the
  default threshold, nrhs 1..64; identical = all three bit-identical.
round23_cholesky_accuracy.csv: errors (log2) of X against a 2*bits MPFR Cholesky solve of the same A and B (A and B exact).
  fwd_norm = max|x - x*| / max|x*|; fwd_comp = max_i |x_i - x*_i| / |x*_i| (exponent bound); bwd_norm = ||B - A X||_inf /
  (||A||_inf ||X||_inf + ||B||_inf); bwd_comp = max_i |r_i| / (|A| |x| + |b|)_i (Oettli-Prager), residuals with exact products
  and one mpfr_sum at 4*bits+64. Maximum over the nrhs columns. Methods: limbforge_blocked (block 32) and mpfr_sequential
  (the consumer-style MPFR Cholesky and substitution at bits).
